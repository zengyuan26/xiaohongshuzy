# 轮播结构、视觉和生图

## 先写页面任务

每页先写一个动词，确认页面有增量：

```text
P1 提出冲突或结果
P2 兑现第一层答案
P3 展示全局结构或比较标准
P4 解释关键差异或原因
P5 给出分支、步骤或反例
P6 交付决策、清单或边界
```

页数由证明单元决定。三页可以讲清就不要凑九页；需要完整比较时也不要为了“简洁”删掉关键条件。

## 每页合同

```text
本页任务：
用户读完新增了什么：
主标题：尽量一句话说结果
正文：只保留完成任务所需的信息
视觉关系：对照 / 层级 / 顺序 / 分支 / 数量 / 时间 / 前后
证据：数据 / 来源 / 实物 / 截图 / 步骤 / 真实经历
与下一页的关系：
```

连续语言因果、人物声线和情绪爆发如果无法转成静态关系，应建议口播或长文；用户坚持时做条件适配版，不用装饰性插画伪装证明。

## 视觉系统

- 默认3:4竖版，常用输出1080×1440；用户或平台另有要求时从其要求。
- 一套轮播统一画幅、栅格、边距、字体层级、色彩语义和图标语言。
- 每页只保留一个视觉焦点。标题、主体、说明的层级必须在手机缩略图中成立。
- 颜色承担语义：正常/主体、错误/风险、步骤/强调不要混用。
- 封面优先“一个强标题＋一个核心视觉关系”，不是满屏小字。
- 插图页必须叙事时，用人物、动作、环境和结果表达；需要回查时，用表格、流程、矩阵和清单表达。

## 真实性

- 真实产品比较优先统一角度实拍；没有真实图时明确使用示意图。
- 真实改造、客户反馈、门店、加工过程和效果必须使用授权材料。
- AI人物应避免冒充真实专家、客户或事件当事人。
- 数据图表标明来源和时间；不能用视觉精致度替代证据。

## 生图提示词合同

逐页提示词应包含：

```text
用途与平台：小红书第N页，3:4，1080×1440
本页任务：
必须逐字呈现的文字：
主体场景或结构关系：
构图与留白：
色彩及其语义：
字体层级：
与全套保持一致的元素：
禁止事项：乱码、错别字、额外小字、虚假Logo、无关装饰、冒充实拍
```

文字准确性高于画面复杂度。长段文字、复杂表格或连续出现中文错字时，改用“生成无字底图＋后期固定排版”，不要反复赌模型能正确排长文。

## 终检

- P2是否已经兑现封面？
- 每页是否增加新事实、变量、步骤、分支或结论？
- 删除视觉后是否会损失理解或回查价值？
- 标题中的数字、效果、身份和来源是否可核实？
- 最后一页是否交付了用户真正要拿走的东西？
