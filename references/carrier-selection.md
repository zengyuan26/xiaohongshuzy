# 图文判断与类型选型

## 先输出选型卡

```text
图文适配结论：适合 / 条件适合 / 不适合
决定性理由：哪一种静态关系或回查需求承担证明
若不适合：损失最大的内容；建议载体
主类型：只选一个
辅助类型：最多一个，并绑定具体页面
用户拿走物：知识地图 / 比较尺 / 决策 / 步骤 / 证据 / 立场 / 模板 / 体验
主证明单元：本篇最有说服力的事实、对照、步骤、画面或来源
主视觉关系：数量 / 空间 / 对照 / 层级 / 顺序 / 分支 / 时间线 / 利益关系 / 前后变化
主行为：完读 / 收藏复用 / 评论讨论 / 精准转发 / 关注追更
建议页数：由证明单元决定
研究档位：R0 / R1 / R2 / R3
标题机制：
封面结构：
证据缺口与禁用边界：
```

## 适合图文的决定性条件

至少满足一项，并能拆成三页以上不同任务：

- 多个对象需要在同一尺度下比较；
- 层级、空间、流程、产业链、资金流或利益关系本身就是证明；
- 参数、步骤、清单、分支或模板需要反复回查；
- 每一页都能增加事实、变量、选择或反转；
- 截图、实物、数据、前后变化或原始材料能够增强可信度。

如果多数页面只是换一句话强调同一观点，不要硬做轮播。

## 不优先图文

| 不可替代内容 | 更适合载体 | 图文化损失 |
|---|---|---|
| 声线、停顿、情绪爆发、连续语言因果 | 口播 | 观点力度和陪伴感 |
| 动作、运动、空间变化、真实过程 | 短视频 | 过程证据和真实性 |
| 多层引用、反例、完整长因果链 | 长文 | 论证与来源回查 |
| 只有一句价值判断 | 口播或短文 | 图片只剩装饰 |
| 必须依赖真实客户或效果，却没有授权材料 | 先补证据 | AI图片会冒充事实 |

## 主类型路由

| 主类型 | 用户真正要解决的问题 | 推荐结构 | 主视觉关系 |
|---|---|---|---|
| 资料压缩型 | 信息太多，替我整理 | 总览→分组→重点→索引 | 数量、分类 |
| 知识地图型 | 内部怎么组成 | 冲突→全图→分层→位置→风险 | 层级、空间 |
| 实物比较型 | A和B差在哪 | 标准→同维对照→结论→适用人群 | 对照 |
| 决策代办型 | 我该选哪个 | 场景→分支→推荐→不适用 | 分支、矩阵 |
| 诊断处方型 | 哪里错了，怎么改 | 翻车→原因→分级→步骤→复查 | 顺序、分支 |
| 体验种草型 | 是否值得体验 | 场景→体验→细节→适合/不适合 | 实景、前后 |
| 外部转译型 | 外部知识与我何干 | 来源→原问题→白话→现实关系→判断 | 原文、人物、关系 |
| 利益冲突型 | 谁获利、谁承担代价 | 动作冲突→事实→利益分配→普通人代价 | 利益、权力、资金流 |
| 价值观演练型 | 两难关系怎么选 | 难题→A→B→连续加码→明确原则 | 对话、岔路 |
| 热点复盘型 | 为什么翻车 | 第一反应→事实→错误→修复→站队 | 时间、因果 |
| 改造见证型 | 改变是否有效 | 改造前→动作→改造后→成本与代价 | 前后、时间线 |
| 实验调查型 | 网上说法是否成立 | 假设→方法→过程→结果→异常→边界 | 对照、数据 |
| 模板交付型 | 能否直接拿去用 | 场景→模板→示例→使用→边界 | 表格、流程 |
| 个人复盘型 | 你怎么走过来的 | 结果→困境→错误→转折→验证 | 时间线、真实照片 |

辅助类型最多一个，并明确例如“P5使用决策分支”。漫画、实拍、研究报告和AI插画只是表现形式，不是主类型。

## 标题与封面路由

| 入口 | 适用 | 示例公式 |
|---|---|---|
| 数字完整性 | 资料、地图、模板 | `一张图看懂X的6层结构` |
| 错误与损失 | 诊断、教程 | `别再X了，这一步错了会Y` |
| 异常信号 | 症状、事故 | `出现这3个信号，问题可能不在X` |
| 同维冲突 | 比较、决策 | `都叫X，A和B真正差在这里` |
| 隐藏结构 | 科技、商业 | `你看到的是X，决定结果的是Y` |
| 利益动作 | 商业、热点 | `A高估了X，却低估了Y` |
| 具体结果 | 改造、体验 | `从X到Y，我只改了这3处` |

封面只完成一个任务：清单承诺、结果展示、结构关系、人物来源或冲突代价五选一。默认只放主标题和必要副标题，不把整篇摘要塞到封面。
