# 示例：分享链接失效的食品安全题材

## 用户输入

```text
肉类清洁小妙招，肉买回家别急着下锅。看这个链接能不能做个图文类内容？
```

链接已经失效，无法读取原笔记。

## 正确路由

1. 明确说明链接不可访问，不能声称已经看完；
2. 题目涉及食品安全，研究档位提升到R2；
3. 不沿用“清洁小妙招”的模糊入口，先核查权威食品安全资料；
4. 判断题材需要错误/正确对照、肉类分支和操作回查，适合诊断处方型图文；
5. 用“冲洗可能造成交叉污染”作为待核实核心判断，而不是先写成事实；
6. 评论争议围绕“鸡肉能不能洗”“排骨有骨屑怎么办”等真实条件差异展开。

## 图文选型卡

```text
图文适配结论：适合
决定性理由：需要同时看见错误动作、污染路径、肉类分支和正确步骤
主类型：诊断处方型
辅助类型：P3使用决策分支
用户拿走物：肉类处理判断表
主证明单元：权威食品安全来源＋交叉污染路径
主视觉关系：错误/正确对照、分支、顺序
主行为：收藏复用
研究档位：R2
```

## 页面任务

```text
P1 生肉越洗，厨房可能越脏
P2 清水冲洗为什么不能等于杀菌
P3 猪牛羊、禽肉、肉馅、带骨肉分别怎么处理
P4 四个最容易造成交叉污染的动作
P5 有明显骨屑或表面异物怎么办
P6 真正需要清洁的是手、水槽、刀具和案板
P7 一张处理清单完成复查
```

## 不能做的事

- 把打不开的原笔记改写成“原文提到”；
- 把盐、醋、面粉或浸泡写成可靠消毒方法；
- 用AI厨房图冒充实验结果；
- 为了评论制造“洗肉派愚蠢、不洗派正确”的身份对立；
- 未经授权直接登录或发布笔记。
