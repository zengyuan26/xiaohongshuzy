# 小红书研究、评论与事实核验

## 研究档位

| 档位 | 最低工作 | 结论权限 |
|---|---|---|
| R0 | 回查用户材料、既有规则和近期重复 | 直接生产，不外推平台规律 |
| R1 | 至少2篇内容、证明方式、结构和载体同构的完整案例 | 正式单篇校准 |
| R2 | 目标获取5—10篇近期相关图文，至少读取3篇有信息量的评论 | 平台表达校准；不足时标明范围 |
| R3 | 目标获取10篇以上跨账号样本，并结合账号历史数据或后续复盘 | 方法候选，不直接升级规则 |

健康、食品安全、医疗、法律、投资收益、产品效果、人物引语和争议事件至少提高一档。用户只是只改封面、修正错字或改单页时使用R0，不要机械启动大规模研究。

## 选择样本

优先顺序：同一用户问题与场景 → 同一证明方式 → 同一结构与主行为 → 同平台近期内容 → 公开互动相对突出。

每篇样本记录：

```text
标题、链接、观察时间：
可访问范围：封面 / 标题 / 正文 / 全部页面 / 评论
可见数据：点赞 / 收藏 / 评论 / 粉丝量；缺失写不可得
用户问题和场景：
主类型和主行为：
标题发动机与封面关系：
逐页任务：
主证明单元：
评论中的真实问题：
可借：
不可借：
证据等级：完整案例 / 结构案例 / 候选观察
```

同一行业不等于同构。高赞不证明标题或封面导致传播；低赞也不证明没有转化。无法分离投放、明星热点、抽奖或账号体量影响时，不做因果归因。

## 评论证据卡

按六类提取：具体麻烦、身份场景、理解缺口、经验反例、质疑与证据要求、后续问题。

- 少量评论只能证明“出现过这种问题”，不能代表全部用户；
- 评论中的健康、食品安全、法律、投资和历史说法不能直接当事实；
- 争议点应来自真实条件差异，不制造假对立；
- 短摘原话并保留上下文，不批量搬运评论。

## 事实校验卡

```text
已核实事实：有来源、日期和适用范围
原作者主张：明确是谁说的
机制解释：解释事实但不夸大因果
合理推断：明确标注推断和依据
个人经验：只代表本人或授权案例
禁止主张：证据、资格或平台边界不支持
```

来源优先：法规、政府、标准、论文、企业原始公告和完整材料 → 专业来源 → 新闻报道 → 平台笔记与评论线索。

## 工具或链接不可用

- 链接打不开、失效或只有分享口令：明确说出可访问范围，不得声称已经看完。
- 样本达不到目标数量：用已有高质量样本做有限结论，标明数量与缺口，不编造Top10。
- 评论不可见：不编造共鸣点，改用用户提供的真实问答或标为待验证假设。
- 无法联网核实：移除高风险事实或请用户补原材料。
- 没有真实图片：可做结构图、步骤图和示意图，不能冒充门店、客户、加工、实验或效果证明。
